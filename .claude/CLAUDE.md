# Claude Code sample (not loaded by Cursor)

This folder is a **conceptual mapping sample**, not something Cursor applies.

- Claude Code path-scoped rules live in `.claude/rules/` and use `paths:`
- Cursor Project Rules live in `.cursor/rules/*.mdc` and use `globs:`
- Run `npm run map-rules` to print the conceptual mapping

Cursor does not automatically import Claude `paths:` rules. Skills import was
tested separately and is not claimed here.
